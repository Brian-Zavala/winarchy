# Themes

Winarchy comes with Omarchy's twenty-two themes. You can select between them via _Style > Theme_ in the Omarchy menu (`Super + Space`) or hop directly to the theme selector using `Super + Ctrl + Shift + Space`.

Each theme styles the top bar and menus, GlazeWM's window borders, the Windows accent color and light or dark mode, Windows Terminal, Flow Launcher, VS Code, Claude Code, Neovim (Omarchy-style configs), btop, Herdr, and the wallpaper and lock screen. Chrome and Brave get the theme's toolbar color too, once you've run `winarchy browser-setup` (one admin prompt, because the color is a browser policy).

Themes have a set of background images that you can pick between using `Super + Ctrl + Space`. See [backgrounds](39-backgrounds.md).

Missing colors in a theme are filled in exactly the way Omarchy's `omarchy-theme-color` does, so a theme looks the same here as on Omarchy. You can even [make your own theme](43-making-your-own-theme.md).

### Turning a target off

Every one of those targets can be switched off on its own in your settings, for example `"themeTargets": { "vscode": false }`. See [dotfiles](31-dotfiles.md) for the full list, and for how Herdr picks its theme.
