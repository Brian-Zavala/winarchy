# Coming From Mac or Windows

Winarchy is still Windows underneath, so every app you had keeps working. What changes is how you get around: windows tile themselves, there's no taskbar, and almost everything is a `Super` key away. `Super` is the Windows key.

Here's where the things you're used to went:

| You're used to | In Winarchy |
|---|---|
| The Start menu | `Super + Space` opens the Omarchy menu, and `Super + Alt + Space` the app launcher. `Ctrl + Esc` still opens Start |
| The taskbar | The top bar. Running windows and the tray sit behind its chevron. See [the top bar](05-the-top-bar.md) |
| Minimizing | Nothing minimizes, since there's no taskbar to bring it back from. Windows tile side by side, and [workspaces](04-navigation.md) hold the rest |
| Dragging windows around | They tile themselves. `Super + Arrows` moves focus, `Super + Shift + Arrows` moves the window, and `Super + drag` moves one with the mouse |
| `Alt + Tab` | Still there. `Super + 1..0` jumps straight to a workspace |
| `Win + V` clipboard history | `Super + Ctrl + V`. See [clipboard](08-unified-clipboard-history.md) |
| `Win + Shift + S` | `Print`. See [screenshots](12-screenshots-recording.md) |
| Task Manager | `Super + Ctrl + T` opens btop; right-click the bar's CPU icon for Task Manager |
| `Win + L` | Still locks, as does `Super + Ctrl + L` |
| Control Panel and Settings | _Setup_ in the Omarchy menu has the panels you'll need most |
| Uninstalling | `winarchy uninstall` puts Windows back exactly as it was. See [system snapshots](47-system-snapshots.md) |

Press `Super + K` any time to see every key. The full list is in [hotkeys](07-hotkeys.md).

### Coming from a Mac

`Super + C`, `Super + V`, `Super + X` and `Super + A` copy, paste, cut and select all, so the Command-key habit keeps working in every app.
