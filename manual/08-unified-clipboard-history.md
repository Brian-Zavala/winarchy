# Unified Clipboard & History

Copying and pasting in a terminal usually needs a different key than everywhere else. Winarchy fixes that the way Omarchy does, with one set of keys that works in every app:

| Hotkey | Function |
|---|---|
| `Super + C` | Copy |
| `Super + V` | Paste |
| `Super + X` | Cut |
| `Super + A` | Select all |

They work in Windows Terminal, browsers, editors and everything else, so you never have to think about which app you're in. Coming from a Mac, it's the Command-key habit you already have.

Pictures paste into terminals too. Copy a screenshot or an image, then press `Ctrl + V` or `Super + V` in Windows Terminal: Winarchy saves it as a PNG and pastes its path, which is how Claude Code and other command-line tools take an image.

### History

`Super + Ctrl + V` opens the clipboard history: everything you've copied recently, text and images alike. Pick one to paste it. It's Windows' own history, so it's also on _Trigger > Clipboard_ in the Omarchy menu.

### Emoji

`Super + Ctrl + E` opens the emoji picker, as does _Trigger > Emoji_.
