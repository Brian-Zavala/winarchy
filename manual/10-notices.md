# Notices

Since the bar is minimal, Winarchy can show you the time, battery and weather as a notice on screen whenever you ask, just like Omarchy.

| Hotkey | Function |
|---|---|
| `Super + Ctrl + Alt + T` | The time and date |
| `Super + Ctrl + Alt + B` | The battery, on a laptop |
| `Super + Ctrl + Alt + W` | The weather |
| `Super + Ctrl + Alt + D` | The calendar |

### Notifications

`Super + Shift + Alt + ,` opens Windows' notification history. `Super + Ctrl + ,` turns on do not disturb, which silences them until you turn it off again; a bell in the bar shows while it's on.
