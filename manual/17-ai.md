# AI

Winarchy follows Omarchy Quattro's AI workflow: a default coding agent a key away, Herdr layouts that put it next to your editor, and the agent usage panel in the bar.

## Coding agents

_Trigger > Agent_ in the Omarchy menu, or right-clicking the bar's agent icon, starts your default coding agent in its own terminal window, with that agent's own "don't stop to ask" flags, the same ones Omarchy uses. Winarchy knows these:

| Agent | Name |
|---|---|
| Claude Code | `claude` |
| Codex | `codex` |
| GitHub Copilot | `copilot` |
| OpenCode | `opencode` |
| Crush | `crush` |
| Cursor CLI | `cursor-agent` |
| Grok | `grok` |
| Antigravity | `agy` |
| Muse Code | `muse` |
| Oh My Pi | `omp` |
| Ori | `ori` |
| Pi | `pi` |
| Hermes | `hermes` |
| OpenClaw | `openclaw` |

Claude Code is the default once it's installed (Omarchy leaves the choice to you, and so does Winarchy until then). Choose another under _Setup > Defaults > Agent_, which starts it right away, or with `winarchy default-agent <name>`, and that one stays the default. `winarchy agent list` shows which are installed and which is the default. An agent that isn't installed yet says how to install it; with no default and no Claude Code, the agent key opens the chooser.

The Herdr layouts take Omarchy's shorthands for them: `c` is OpenCode, `cx` is Claude Code, `cy` is Codex, and `a` is your default agent, so `hdl cx` puts Claude Code next to your editor. See [shell functions](20-shell-functions.md).

## Agents panel

A robot icon in the bar shows every AI coding subscription on the PC, as Omarchy's agents panel does. Hover it for the plan, the rate limits and today's tokens. Click it for the panel:

- **Tokens today** across every agent, at the top, and `+` (or `a`) to add a subscription: another Claude Code or Codex account.
- **Each subscription** with its plan and a meter for each limit (the 5-hour session, the week, and any model's own), with the time left until it resets. Hover a meter for the exact percentage. Your default agent is marked _Default_; another installed agent has _Make default_, which makes it the default and starts it. Codex also shows its free limit resets, and when the next one expires. Click a subscription's name for its tokens by day over the last week and by model.
- **Sign in**, when Claude Code's saved sign-in has expired: it runs `claude auth login` in a terminal (`winarchy agent-login claude`), then refreshes the limits.
- **Make something**: _Theme_, _Plugin_ and _App_ start your default agent in its own window, asking what you'd like, then build it and switch it on. A theme lands in your themes folder, a plugin is a [Zebar](https://github.com/glzr-io/zebar) widget pack of its own that follows your theme, and an app goes in Start. The guides the agent follows are in the `agents\make` folder of the Winarchy code. From a terminal, it's `winarchy agent-make theme`.

`j` and `k` (or the arrow keys) move through the panel's buttons, `Enter` presses one, `a` adds a subscription, `r` refreshes, and `Esc` closes it.

### Several accounts

Have a work and a personal subscription? Press `+` in the panel (or run `winarchy agent-account add`). Your existing sign-in stays the _Main_ account. The new account signs in in a private browser window, so the browser's own sign-in stays out of it. Codex signs in with a device code, which must be turned on in ChatGPT's security settings.

- **Each account** gets its own section in the panel, with its limits. The one in use is marked _Active_; _Use_ switches to another. New agent windows, Herdr panes and `claude` or `codex` typed in PowerShell use the active account. Sessions already running stay as they are.
- **Autoswitch** moves an agent to its account with the most left when the active one reaches 95% of a limit, and tells you. It's off by default; the _Autoswitch_ toggle turns it on for each agent (`winarchy agent-account mode claude auto`). With it off you still get a notice.
- **Conversations, skills, plugins and settings stay shared.** Each account keeps only its own sign-in, in `%USERPROFILE%\.winarchy\state\omarchy\agents\accounts`. Everything else links to `~\.claude` or `~\.codex`.
- **Manage them** with `winarchy agent-account list`, `rename claude/work "Side"` and `remove claude/work`. Removing one never signs it out anywhere, and never touches your conversations.

Install and update set this up for you, and uninstall takes it out again, links first, so your own `~\.claude` is never touched.

Omarchy's own usage collectors do the counting, ported to Windows:

- **Claude Code**: its transcripts, plus the 5-hour and weekly limits straight from Anthropic, with Claude Code's own sign-in. The sign-in never leaves that one request and never goes into a file.
- **Codex**: its sessions, plus its limits from `codex app-server`.
- **Antigravity**: its session history and prompt counts from `~/.gemini/antigravity-cli`.
- **Fireworks**: `FIREWORKS_API_KEY` or `~/.fireworks/auth.ini`.

The icon appears once an agent is installed or has something to show, and refreshes every 15 minutes. It needs Python 3, which the installer sets up and `winarchy doctor` checks. `"agentUsage": { "enabled": false }` in your settings removes it, and `"providers": { "codex": { "enabled": false } }` hides just one. See [dotfiles](31-dotfiles.md).

## AI apps

_Install > AI_ in the Omarchy menu has ChatGPT (from the Microsoft Store), Claude Desktop, OpenClaw, Perplexity, and two ways to run models on your own PC: [Ollama](https://ollama.com) and [LM Studio](https://lmstudio.ai). _Install > AI Agents_ installs the coding agents whose packages could be checked (Claude Code, Codex, GitHub Copilot, OpenCode and Grok) with npm, so it needs Node.js (_Install > Development_). The others are set up from _Setup > Defaults > Agent_, which says how.
