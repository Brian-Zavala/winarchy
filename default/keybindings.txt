OMARCHY-STYLE KEYBINDINGS (Winarchy)            Super = Windows key
=====================================================================

MENUS
  Super + Space                 Omarchy menu (also: left click the bar logo)
  Super + Alt + Space           App launcher (Flow Launcher)
  Super + Escape                System menu (lock, suspend, restart, shutdown)
  Super + K                     Keybindings (this list)
  Super + Ctrl + Space          Background picker
  Super + Ctrl + Shift + Space  Theme picker (recolors everything + background)
  Super + Ctrl + C              Capture menu
  Super + Ctrl + O              Toggle menu
  Super + Ctrl + H              Setup (hardware) menu

WORKSPACES   (1-0 are split across your monitors, left to right)
  Super + 1..0                  Go to workspace
  Super + Shift + 1..0          Move window to workspace (and follow)
  Super + Shift + Alt + 1..0    Move window to workspace silently
  Super + Tab / Shift + Tab     Next / previous workspace
  Super + Ctrl + Tab            Previous (last used) workspace
  Super + scroll wheel          Next / previous workspace
  Super + S  or  Super + `      Scratchpad workspace
  Super + Alt + S / Shift + `   Send window to scratchpad
  Super + Shift + Alt + Arrows  Move whole workspace to other monitor
  Ctrl + Alt + Tab              Focus next monitor (+ Shift: previous)

WINDOWS
  Super + W  or  Super + Q      Close window (a game too: see GAMES)
  Super + Arrows                Move focus
  Super + Shift + Arrows        Swap / move window (crosses monitors)
  Super + T                     Toggle floating / tiling
  Super + F                     Fullscreen
  Super + Alt + F               Full width (keeps bar + gaps)
  Super + O                     Pop out (float + always on top)
  Super + J                     Flip layout: side-by-side <-> stacked
  Super + - / =                 Shrink / grow width   (100px)
  Super + Shift + - / =         Shrink / grow height
  + Alt  (fine, 25px)           + Ctrl  (coarse, 300px)
  Super + Left drag             Move window
  Super + Right drag            Resize window
  Super + Backspace             Toggle window transparency
  Super + Shift + Backspace     Toggle window gaps
  Super + Shift + Space         Toggle top bar (stays off until toggled back; also: winarchy bar on|off)
  Super + M  or  Super + Home   Restore every minimized window (the taskbar is hidden: this is
                                the way back if one ever gets minimized)

GAMES   (automatic: Windows' Game Bar, Steam/Epic/Xbox/GOG/EA/Ubisoft's own folders,
         Playnite's own games, config.json "gameDirs" and "games")
  A game in front               Not tiled by GlazeWM; the top bar hides on its monitor;
                                nothing pops over it (bar restarts, display changes and
                                the screensaver wait until you leave or close the game)
  Switch away and back          The game itself is left alone until it closes (workspace
                                repair and a re-tiling redraw wait for that; the bar still
                                comes back on its own). Switching to its own workspace
                                again brings the game back to front
  Super + W  or  Super + Q      Close the game (again within 15 s: force-quit)
                                (games that run as administrator: winarchy game-setup once)
  Super + Ctrl + G              Mark the focused window as a game by hand (missed by the
                                checks above) and remember it in config.json
  Bar gamepad icon              Shown while a game is open. Click: back to the game,
                                right click: close it (twice: force-quit)
  Gamepad buttons / sticks      Count as activity: no screensaver mid-game; they also end it
  "gameMode": false             In config.json: turn all of this off

CAPTURE   (no PrtScn key on your laptop? Super + Ctrl + C opens the Capture menu)
  Print                         Screenshot (region, Snipping Tool)
  Super + Print                 Full screenshot saved to Pictures\Screenshots
  Alt + Print                   Screen recording (Snipping Tool)
  Super + Shift + Print         Text capture: snip a region, its text is copied (OCR)
  Super + Ctrl + Print          Color picker (click copies #rrggbb)

UTILITIES
  Super + C / V / X / A         Copy / paste / cut / select all
  Super + Ctrl + V              Clipboard history
  Super + Ctrl + E              Emoji picker
  Shift + F9  or Super+Ctrl+X   Voice dictation (talk -> types; again to stop)
  Super + Ctrl + I              Stay awake (coffee icon in the bar)
  Super + Ctrl + N              Nightlight (moon icon in the bar)
  Super + Ctrl + ,              Do not disturb (bell icon in the bar)
  Super + Ctrl + Q              Calculator
  Super + Ctrl + T              Activity (btop; right click the bar CPU icon: Task Manager)
  Super + Ctrl + A              Audio panel (output device + volumes; again: close)
  Super + Ctrl + B              Bluetooth panel (devices, on/off; again: close)
  Super + Ctrl + W              Network settings
  Super + Ctrl + D / P          Display / power settings
  Super + Ctrl + Alt + T / B / W  Show time / battery / weather
  Super + Ctrl + Alt + D        Calendar
  Super + Shift + Alt + ,       Notification history
  Super + Ctrl + Z              Zoom in (+ Alt: reset)
  Super + Ctrl + L              Lock  (Win + L also locks)

SYSTEM
  Bar logo: left / right click  Omarchy menu / terminal
  Bar clock: left / right click Calendar / date format
  Bar indicators                Click to turn off (stay awake, nightlight, do not disturb)
  Bar weather / update icons    Click: weather details / update everything
  Bar gamepad icon (game open)  Click: switch to the game, right click: close it (twice: force-quit)
  Bar audio icon                Click: audio panel, right click: mute, scroll: volume
  Bar bluetooth icon            Click: Bluetooth panel
  Idle 2.5 minutes              Screensaver (any key, mouse move or gamepad input ends it)
  Ctrl + Esc                    Windows Start menu
  Super + Shift + Alt + R       Reload GlazeWM config
  Super + Shift + Alt + P       Pause / resume GlazeWM (escape hatch)

HERDR AND CODING AGENTS
  hdl <agent> [<agent2>]        Dev layout: editor, agent right (30%), terminal below (15%)
  hds                           Dev square: editor, diff watch, terminal, agent
  hdlm <agent> [<agent2>]       One hdl tab per subdirectory of the current folder
  hsl <count> <command>         Swarm: N panes in a grid, all running the same command
  Ctrl + Space                  Herdr's prefix (then ? for help) - full list in Learn > Herdr keys
  Super + Ctrl + Return         Herdr: open or re-attach the session (also Menu > Trigger > Herdr)
  Menu > Trigger > Agent        Start the default coding agent, unattended
  Menu > Setup > Default Agent  Choose it (Claude, Codex, Copilot, OpenCode, ...)
  Bar robot icon                Click: agent usage and limits, right-click: start the agent

TERMINAL COMMANDS
  winarchy doctor               Check everything, explain problems (-Fix to repair)
  winarchy theme <name>         Switch theme (winarchy theme list)
  winarchy font <family>        Switch font (winarchy font list)
  winarchy apply                Re-apply after editing your config.json
  winarchy update               Update Winarchy, themes and apps; install anything newly needed
  winarchy herdr status         Herdr: where it is, its config, its theme (herdr install)
  winarchy agent list           The coding agents, and which one is the default
  winarchy uninstall            Back to normal Windows (asks about apps/settings; -DryRun)
