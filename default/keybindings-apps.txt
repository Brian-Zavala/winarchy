APPS  (winarchy launchers; set "launchers": false in config.json to use your own)
  Super + Return                Terminal
  Super + Shift + Return / B    Browser (your default)
  Super + Shift + Alt + B       Private browser window
  Super + Shift + F             File manager
  Super + Shift + N             Editor (Neovim if installed)
  Super + Shift + M             Spotify
  Super + Shift + /             1Password
  Super + Shift + O             Obsidian
  Super + Shift + G             Signal
  Super + Shift + D             lazydocker
  Super + Shift + Alt + M       Cliamp (music in the terminal)
  Super + Shift + W             Omawrite (writing)

  Super + Shift + A             ChatGPT
  Super + Shift + Alt + A       Grok
  Super + Shift + E             HEY
  Super + Shift + Alt + E       HEY: new email
  Super + Shift + C             HEY Calendar
  Super + Shift + Y             YouTube
  Super + Shift + X             X
  Super + Shift + Alt + X       X: new post
  Super + Shift + P             Google Photos (brings an open one back)
  Super + Shift + Alt + G       WhatsApp (brings an open one back)
  Super + Shift + Ctrl + G      Google Messages (brings an open one back)
