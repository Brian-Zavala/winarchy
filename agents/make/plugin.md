# Making a Winarchy bar plugin (a Zebar widget pack)

The usage panel's _Make something > Plugin_ tile hands you this guide. Omarchy's plugins are Quickshell components. Winarchy's bar is [Zebar](https://github.com/glzr-io/zebar), so a plugin here is a Zebar **widget pack**: its own HTML, CSS and JavaScript in a window of its own. First ask what the user wants it to do, then build it, start it, and ask if they want anything changed.

## What a pack can and can't do

A pack is a separate window. It can float anywhere on the screen, sit on the desktop behind other windows, or drop down under the bar the way Winarchy's panels do. It can't put an icon inside Winarchy's own bar. For a small change to how the bar looks, the user's `user.css` in `%USERPROFILE%\.glzr\zebar\omarchy` is the place.

Don't edit anything in `%USERPROFILE%\.glzr\zebar\omarchy`: `winarchy apply` rewrites that folder. A pack in a folder of its own is left alone.

## Where it goes

`%USERPROFILE%\.glzr\zebar\<name>\`. The agent was started in `%USERPROFILE%\.glzr\zebar`. Use a short lowercase name.

```
<name>\
  zpack.json
  <widget>.html
  <widget>.css
  <widget>.js
  zebar.mjs      copied from ..\omarchy\zebar.mjs (the Zebar client, if the widget uses it)
  theme.css      copied from ..\omarchy\theme.css (see "Follow the theme")
  font.css       copied from ..\omarchy\font.css
```

## zpack.json

Zebar 3's format. Winarchy's own is at `..\omarchy\zpack.json`, so read it for more examples.

```json
{
  "$schema": "https://github.com/glzr-io/zebar/raw/v3.0.0/resources/zpack-schema.json",
  "name": "<name>",
  "version": "1.0.0",
  "description": "What it does",
  "tags": [],
  "previewImages": [],
  "repositoryUrl": "",
  "widgets": [
    {
      "name": "<widget>",
      "htmlPath": "./<widget>.html",
      "zOrder": "normal",
      "shownInTaskbar": false,
      "focused": false,
      "resizable": false,
      "transparent": true,
      "includeFiles": ["*.html", "*.css", "*.js", "*.mjs", "*.json"],
      "caching": { "defaultDuration": 0, "rules": [] },
      "privileges": { "shellCommands": [] },
      "presets": [
        {
          "name": "default",
          "anchor": "top_right",
          "offsetX": "-20px",
          "offsetY": "60px",
          "width": "320px",
          "height": "200px",
          "monitorSelection": { "type": "primary" }
        }
      ]
    }
  ]
}
```

- `zOrder` is `normal`, `top_most` (above windows) or `bottom_most` (on the desktop).
- Running a program needs an entry in `privileges.shellCommands`: `{ "program": "<exe>", "argsRegex": "<regex>" }`. Keep it to the one program and the arguments the widget needs.
- Data comes from Zebar's providers (`zebar.createProvider({ type: 'cpu' })`, and also `memory`, `battery`, `network`, `weather`, `media`, `glazewm`, `date`) or from `fetch` of a web API.

## Follow the theme

Link the theme and font files in the page's `<head>`, and give the page's CSS fallbacks:

```html
<link rel="stylesheet" href="./theme.css" id="theme" />
<link rel="stylesheet" href="./font.css" />
```

`theme.css` defines `--bg`, `--fg`, `--accent`, `--alert`, `--muted`, `--selection`, `--red`, `--green`, `--yellow`, `--blue`, `--magenta`, `--cyan`, `--orange` and the `--bg-*` / `--fg-*` steps. `font.css` defines `--font` and `--text-scale`. Once the pack has its own copies, Winarchy rewrites them on every theme and font change. It only rewrites a copy whose first line is still Winarchy's `/* Generated by winarchy ... */`, so copy the files unchanged and put the pack's own styles in its own CSS. Reload the theme every few seconds so a change shows without a restart:

```js
setInterval(() => { document.getElementById('theme').href = `./theme.css?t=${Date.now()}`; }, 5000);
```

Match Winarchy's panels: a flat card in `--bg` with a 2px `--fg` border, no shadow or glow, the Nerd Font from `--font`, and text in `--fg`.

## Start it

1. Add it to Zebar's startup list, `%USERPROFILE%\.glzr\zebar\settings.json`. **Keep** the existing `omarchy` entry and add yours to `startupConfigs`:

   ```json
   { "pack": "<name>", "widget": "<widget>", "preset": "default" }
   ```

2. Start it now, with the Zebar path from `%USERPROFILE%\.winarchy\paths.json` (`zebar`):

   ```powershell
   & (Get-Content -Raw "$env:USERPROFILE\.winarchy\paths.json" | ConvertFrom-Json).zebar start-widget-preset --pack <name> --widget-name <widget> --preset default
   ```

After an edit, run the same command again or restart the bar (Omarchy menu: _Update > Process > Menu Bar_).
